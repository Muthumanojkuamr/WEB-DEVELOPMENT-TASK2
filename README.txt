APEXPLANET WEB DEVELOPMENT INTERNSHIP - TASK 2

FILES
- index.html: Complete responsive website with HTML, CSS and JavaScript.

HOW TO RUN
1. Extract the ZIP file.
2. Open the ApexPlanet_Task2 folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Test the To-Do List by adding, completing (click the task text), and deleting tasks.
5. Test the Contact Form with empty fields, an invalid email, and valid details.
6. Resize the browser to check the responsive layout.

TASK 2 FEATURES
- CSS Flexbox navigation and CSS Grid content layout.
- Responsive layout using a CSS media query.
- Contact form with JavaScript validation.
- Dynamic To-Do List with add, complete, and delete actions.

NOTE
The contact form validates input in the browser only. It does not send messages to an email server.
